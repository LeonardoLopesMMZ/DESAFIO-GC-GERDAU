Curador que ensina

Raio-X do catálogo

Entrada pelo rosto

Rosto, chave do Windows ou liberação do curador. Cada código sabe quem criou.

Não para se algo cair

Sem o serviço de similaridade ou sem o banco, a consulta continua e nada se perde.

Curador com contexto e previsibilidade

  • Pedidos iguais de pessoas diferentes chegam juntos, num cartão só.
  • O MOKKA mostra a sugestão, a certeza dela e o que muda entre os textos.
  • Cada decisão vira regra: a próxima consulta igual já vem com o código certo. E dá para desfazer.
